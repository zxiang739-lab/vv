# FrameFlowAI 数据流（5 种业务模式 × 两套引擎）

> 说明：
> - **VT** = 系统 VTFrameProcessor 引擎（仅 iOS26+）；**CML** = 用户导入 CoreML 引擎。
> - 两套引擎都遵循 `AIFrameProcessingEngine.process(frame:) -> [CMSampleBuffer]`，上层数据流完全一致。
> - 实时链路在 `RealtimePipelineService` 内做「背压」：上一帧未处理完时丢弃新帧。

---

## 实时模式（摄像头 AVCaptureSession，CMSampleBuffer 流转）

### ① 实时补帧（仅插值，不放大）

```
VT:  VTLowLatencyFrameInterpolationConfiguration（numberOfInterpolatedFrames=N）
CML: CoreML 补帧模型（frameA + frameB (+timestep) → 插值帧）

[AVCaptureSession] ──BGRA CMSampleBuffer──▶ RealtimePipelineService
    │  （背压：丢弃积压帧）
    ▼
AIFrameProcessingEngine.process(frame)
    ├─ VT : VTFrameProcessorSession.process
    │       首帧→透传；此后: [插值帧×N, 当前帧]  （PTS 按相位内插）
    └─ CML: CoreMLFrameProcessingEngine.processPipeline
            首帧→透传；此后: [插值帧×N(timestep) 或 1(中点), 当前帧]
    ▼
[AVSampleBufferDisplayLayer] 实时预览（FPS / 延迟监控）
```

### ② 实时超分（仅放大，不插帧）

```
VT:  VTLowLatencySuperResolutionScalerConfiguration（scaleFactor）
CML: CoreML 超分模型（单帧 → 放大帧）

[AVCaptureSession] ──▶ RealtimePipelineService ──▶ Engine.process(frame)
    ├─ VT : [放大帧×1]（PTS = 源 PTS）
    └─ CML: [放大帧×1]
    ▼
[AVSampleBufferDisplayLayer] 实时预览
```

### ③ 实时补帧 + 超分（串联流水线）

```
VT:  Session#1 低延迟插值 → Session#2 低延迟超分
CML: CoreML 补帧 → 对每个插值帧/当前帧再做 CoreML 超分

[AVCaptureSession] ──▶ RealtimePipelineService ──▶ VTFrameProcessorEngine.process
    ├─ VT : 会话链循环（stage 1 输出逐帧作为 stage 2 输入）
    │       [插值帧×N, 当前帧] ──超分──▶ [放大×N+1]
    └─ CML: 先补帧再逐帧超分（同上，输出放大后的全部帧）
    ▼
[AVSampleBufferDisplayLayer] 实时预览
```

## 离线模式（本地视频文件，AVAssetReader / AVAssetWriter）

### ④ 离线补帧（分辨率不变，输出新视频）

```
VT:  VTFrameRateConversionConfiguration（sourceFrameRate → conversionFrameRate）
CML: CoreML 补帧模型

[AVURLAsset] ──▶ OfflinePipelineService
    ├─ AVAssetReaderTrackOutput（BGRA 解压）┐
    │   （引擎侧做源格式适配，见 VT 会话 prepareSourceBuffer）
    ▼
Engine.process(frame) ──▶ [插值帧×K, 当前帧]
    ▼
AVAssetWriterInputPixelBufferAdaptor.append(pixelBuffer, at: 重排 PTS)
    输出帧率 = conversionFrameRate（补帧倍率 = 目标/源）
    ├─ 音频轨复制（AVAssetReaderAudioMixOutput → 收集 → 按序写入）
    ├─ 逐帧串行 + 局部作用域回收（防 OOM）
    ├─ Task.isCancelled 支持取消
    └─ finishWriting → 临时 mp4 ──▶ 保存相册（PHPhotoLibrary）
```

### ⑤ 离线超分（放大输出，不补帧）

```
VT:  VTSuperResolutionScalerConfiguration（高质量，inputType:.video，时序型）
     启动前检查 configurationModelStatus → 需要时 downloadConfigurationModel
CML: CoreML 超分模型

[AVURLAsset] ──▶ OfflinePipelineService
    ├─ AVAssetReaderTrackOutput（BGRA 解压）
    ▼
Engine.process(frame) ──▶ [放大帧×1]   （VT 高质量超分使用 previousFrame/previousOutputFrame 时序上下文）
    ▼
AVAssetWriterInputPixelBufferAdaptor.append(pixelBuffer, at: 重排 PTS)
    输出帧率 = 源帧率；输出分辨率 = 源 × scaleFactor
    ├─ 音频轨复制
    ├─ 逐帧串行 + 防 OOM
    ├─ 可取消
    └─ finishWriting → 临时 mp4 ──▶ 保存相册
```

## 统一接口示意

```swift
// 引擎协议（两套引擎都实现）
protocol AIFrameProcessingEngine {
    func prepare(mode: ProcessingMode, configuration: EngineConfiguration) async throws
    func start() async throws
    func stop()
    func process(frame: CMSampleBuffer) async throws -> [CMSampleBuffer]
    func downloadConfigurationModelIfNeeded() async throws
}

// 实时：摄像头帧 → 引擎 → 预览
cameraService.onSampleBuffer = { sb in pipeline.handleFrame(sb) }   // 背压

// 离线：读一帧 → 引擎 → 写一帧
while let sample = readerOutput.copyNextSampleBuffer() {
    for out in try await engine.process(frame: sample) {
        adaptor.append(CMSampleBufferGetImageBuffer(out)!, at: retimedPTS)
    }
}
```
