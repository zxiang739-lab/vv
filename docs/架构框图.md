# FrameFlowAI 文本版架构框图

## 1. 总体分层（自顶向下）

```
┌────────────────────────────────────────────────────────────────────────┐
│  ① UI 层（SwiftUI 原生 Liquid Glass，无第三方 UI 库）                        │
│  MainView ─ Tab ──┬─ RealtimeView（引擎切换 + 3 种实时模式 + 预览 + 指标）   │
│                   ├─ OfflineView（引擎切换 + 2 种离线模式 + 任务队列）       │
│                   └─ SettingsView（引擎说明 + CoreML 模型导入/删除 + 矩阵）  │
│  组件：GlassCard / GlassSegmentPicker / GlassPrimaryButton / MetricBadge   │
│  包装：RealtimePreviewView（AVSampleBufferDisplayLayer）                   │
│       LiquidGlassPlayerView（自定义 AVPlayer，拖拽/点击/长按/倍速）          │
└──────────────────────────┬───────────────────────────────────────────────┘
                           │ UI 不直接调用推理
┌──────────────────────────▼───────────────────────────────────────────────┐
│  ② ViewModel 层                                                          │
│  MainViewModel    → 引擎/模式选择、能力检测、模型状态、任务队列              │
│  RealtimeViewModel → 驱动 RealtimePipelineService，FPS/延迟刷新            │
│  OfflineViewModel → 任务创建/取消/保存相册（Task.detached 后台执行）        │
│  PlayerViewModel  → AVPlayer 状态机（播放/seek/倍速/长按加速/面板显隐）     │
└──────────────────────────┬───────────────────────────────────────────────┘
                           │
┌──────────────────────────▼───────────────────────────────────────────────┐
│  ③ 媒体服务层（Services）                                                  │
│  CameraService         → AVCaptureSession + AVCaptureVideoDataOutput(BGRA)│
│  RealtimePipelineService→ 建引擎/背压帧调度/预览层/性能埋点                 │
│  OfflinePipelineService→ AVAssetReader 读帧 → 引擎 → AVAssetWriter 输出    │
│  VideoImportService     → 文件选择器视频复制到沙盒                          │

                           │ 只依赖协议
┌──────────────────────────▼───────────────────────────────────────────────┐
│  ④ AI 引擎抽象协议层（AIEngines/AIFrameProcessingEngine）                   │
│  protocol AIFrameProcessingEngine:                                        │
│    kind / capability / modelStatus / state / isRunning                    │
│    lastFrameProcessingTime / outputPixelFormat                            │
│    prepare(mode:configuration:) / start() / stop()                        │
│    process(frame:) -> [CMSampleBuffer] / downloadConfigurationModelIfNeeded│
│  工厂：EngineFactory.make(kind:)                                          │
└───────────────┬─────────────────────────────────┬────────────────────────┘
                │                                  │
┌───────────────▼───────────────┐   ┌──────────────▼─────────────────────────┐
│  ⑤a 系统 VTFrameProcessor 引擎 │   │  ⑤b 用户导入 CoreML 引擎                │
│  （仅 iOS26+，硬件能力检测）      │   │  （iOS26/27 通用，CoreML+MPS）         │
│  VTFrameProcessorEngine       │   │  CoreMLFrameProcessingEngine          │
│   ├─ VTFrameProcessorConfigFactory │   ├─ CoreMLInferenceStage（单模型封装）│
│   ├─ VTFrameProcessorSession      │   ├─ CoreMLModelStore（沙盒存储）       │
│   │   ├─ 低延迟插值/超分配置        │   ├─ CoreMLModelValidator（张量校验）  │
│   │   ├─ 高质量超分/帧率转换配置     │   └─ CoreMLPixelBufferUtility         │
│   │   └─ 系统模型下载/状态上报       │       （BGRA/张量转换、vImage 缩放）    │
└───────────────────────────────┘   └───────────────────────────────────────┘
```

## 2. 双引擎内部结构（对比）

| 维度 | 系统 VTFrameProcessor 引擎 | 用户导入 CoreML 引擎 |
|---|---|---|
| 推理运行时 | VideoToolbox 原生（系统 AI 权重） | CoreML + MPS（GPU/ANE 自动调度） |
| 模型来源 | 系统内置 / 高质量配置按需下载 | 用户导入 mlpackage（沙盒） |
| 系统要求 | 仅 iOS 26+，`isSupported` 检测 | iOS 26 / 27 通用 |
| 实时配置 | `VTLowLatencyFrameInterpolationConfiguration` / `VTLowLatencySuperResolutionScalerConfiguration` | 无（直接用 CoreML 推理） |
| 离线配置 | `VTSuperResolutionScalerConfiguration` / `VTFrameRateConversionConfiguration` | 无（直接用 CoreML 推理） |
| 输入格式 | 直接传 CMSampleBuffer（支持格式则零拷贝） | 统一 BGRA（BGRA 零拷贝直通），张量输入转 RGB float |
| 输出格式 | 依 `destinationPixelBufferAttributes`（通常 420v） | BGRA |

## 3. 自定义 AVPlayer 播放器结构

```
LiquidGlassPlayerView（SwiftUI）
 ├─ VideoLayerView（UIViewRepresentable，AVPlayerLayer，.resizeAspect）
 ├─ 点击画面 → viewModel.toggleControls()（面板显隐）
 ├─ 长按画面 → onLongPressGesture(pressing:) → beginBoost / endBoost（3x 临时加速）
 └─ 控制面板（液态玻璃底栏）
     ├─ 进度条（DragGesture：拖动实时预览→updateDragPreview，松手→seek）
     ├─ 播放/暂停按钮
     ├─ 时间显示（current / duration）
     └─ 倍速档位（0.5x / 1.0x / 1.5x / 2.0x，AVPlayer.rate）
PlayerViewModel：周期时间观察（addPeriodicTimeObserver）、播放结束通知、seek(tolerance:.zero)
```
